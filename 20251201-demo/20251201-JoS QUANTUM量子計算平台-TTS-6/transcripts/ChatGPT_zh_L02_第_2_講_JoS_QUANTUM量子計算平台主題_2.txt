2.1 JoS QUANTUM 的結構性建模理念

2.1.1 類比：從電路網路到量子網路

JoS QUANTUM 的一大特點，是使用類似電子電路設計的模組化風格，來建模量子系統。概念上，

 在經典電路裡：

 元件（電阻、電容、電感、OpAmp...）對應到某種輸入–輸出關係（常為微分方程）。

 連線（wire）決定電壓/電流的約束與拓樸。

 在 JoS QUANTUM 裡：

 元件對應到某種量子操作：單量子閘、多體耦合、退相干通道、測量器等。

 連線決定 qubit / qudit / 模式之間的張量結構與作用順序。

在數學層面上，每個元件實現的是一個映射：

 對於純態：大寫花體的 U，從希爾伯特空間 H 的 n 次張量積，映到同一個 H 的 n 次張量積。
 （幺正演化）。

 對於摻雜雜訊的情境：大寫花體的 E，從 H 的 n 次張量空間上的有界線性算符，映到 H 的 n 次張量空間上的有界線性算符。
（完全正跡保持的量子通道）。

JoS QUANTUM 平台讓你可以把這些映射封裝成模組，並像搭積木一樣用 GUI 或程式方式組裝。

2.4.1 量子通道數學回顧

一個一般的量子通道 這個念作：「花體的大寫 E」。

2.4.2 JoS QUANTUM 中的噪聲元件：以振幅衰減通道為例

單 qubit 振幅衰減通道（Amplitude Damping, AD）定義為：
K 下標零，等於一個二乘二的矩陣，第一列是「一、零」，第二列是「零、根號一減 gamma」。 

逗號，K 下標一，等於一個二乘二的矩陣，第一列是「零、根號 gamma」，第二列是「零、零」。

E 下標 A D 作用在 rho 上，等於 K 零、rho、K 零的 dagger，加上 K 一、rho、K 一的 dagger。

其中 gamma 落在零到一之間。
 為衰減機率（可由時間與 這個念成：**T 一**。
 參數導出）。

JoS QUANTUM 可實作為一個 QuantumChannel 型態元件，偽碼示意：

from josquantum import QuantumChannel

class AmplitudeDamping(QuantumChannel):
 def __init__(self, gamma):
 super().__init__(num_qubits=1, name="AD(gamma)")
 self.gamma = gamma

 def kraus_ops(self):
 g = self.gamma
 K0 = np.array([[1, 0],
 [0, np.sqrt(1-g)]], dtype=complex)
 K1 = np.array([[0, np.sqrt(g)],
 [0, 0]], dtype=complex)
 return [K0, K1]

 def apply(self, rho):
 Ks = self.kraus_ops()
 return sum(K @ rho @ K.conj().T for K in Ks)

數學上，可以直接檢查：
K 零的 dagger 乘上 K 零，加上 K 一的 dagger 乘上 K 一，等於前面那個二乘二矩陣，第一列是一零，第二列是零一減 gamma，加上後面那個二乘二矩陣，第一列是零零，第二列是零 gamma，最後等於單位算符 I。

因此通道是 TP；且由 Kraus 表示可知為 CP。這些條件可作為 JoS QUANTUM 元件在建構時的自動驗證邏輯的一部份。

2.5.2 JoS QUANTUM 中的 measurement block：Z-基底測量

以單 qubit Z-基底測量為例：
M 零等於 ket 零 bra 零，

M 一等於 ket 一 bra 一。

則
p 括號零，等於，M 零乘上 rho 的 trace，等於，bra 零、rho、ket 零。

p 括號一，等於，M 一乘上 rho 的 trace，等於，bra 一、rho、ket 一。

在 JoS QUANTUM 的偽碼表達可能為：

from josquantum import QuantumMeasurement

class ZMeasurement(QuantumMeasurement):
 def __init__(self):
 super().__init__(num_qubits=1, name="Z-meas")

 def measure(self, rho):
 # probabilities
 p0 = np.real(rho[0, 0])
 p1 = np.real(rho[1, 1])
 outcome = np.random.choice([0, 1], p=[p0, p1])
 # post-measurement state
 if outcome == 0:
 M = np.array([[1, 0], [0, 0]], dtype=complex)
 else:
 M = np.array([[0, 0], [0, 1]], dtype=complex)
 rho_post = M @ rho @ M.T.conj()
 rho_post /= (p0 if outcome == 0 else p1)
 return outcome, rho_post

2.8 誤差分析與 JoS QUANTUM 的符號 / 數值雙重驗證

2.8.1 模型誤差來源

在一個 JoS QUANTUM 建構的量子電路模型中，誤差可能來自：

 物理雜訊建模誤差（ex: 使用過於簡化的 AD + dephasing 模型）。

 符號級驗證：對簡化小模型，直接比對解析解。
