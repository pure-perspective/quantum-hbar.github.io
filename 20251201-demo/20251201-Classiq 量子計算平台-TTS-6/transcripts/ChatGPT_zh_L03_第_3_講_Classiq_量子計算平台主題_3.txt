3.1 高階規格到電路合成的形式化模型

Classiq 的核心理念是：使用者不直接設計閘級電路，而是描述「要做什麼」而非「怎麼做」。本節先用數學語言形式化這個過程。

3.1.1 問題空間與設計空間

設一個量子演算法的「意圖」可抽象為一族允許的量子通道集合：
F 等於一個集合，裡面元素叫做 Phi 下標 theta， 
從輸入的希爾伯特空間映到輸出的希爾伯特空間， 
其中 theta 落在參數空間 Theta 裡面。

其中：

 H 下標 in，逗號，H 下標 out。
 為輸入與輸出 Hilbert 空間；

 希臘大寫 Theta。
 是參數空間；

 大寫的 Phi，下標是 θ。
 是完全正且跡保持 (CPTP) 的量子通道。

實務上，Classiq 允許使用者指定的是：

 功能規格：例如一個 unitary U
，或一個近似 unitary 的目標 唸作：「U 上面加一個波浪號」。
，或更一般的量子管線（含測量、重置）；

C calligraphic 等於一個集合，裡面包含所有的 C，這些 C 呢，都是在可用的硬體跟閘庫上可以實現的量子電路。

每個電路 大寫的 C 是集合花體 C 裡面的一個元素。

Classiq 的合成問題可表述為下列約束最佳化問題：
給定：功能規格 Spec，約束集合 Constr，還有一個代價函數 Cost，定義在集合 C 上，把 C 映到實數。

3.1.2 資源度量與成本函數

在 NISQ 與中長期 FTQC 場景中，最常見的資源度量包括：

 T 門數：T 括號 C。

 邏輯錯誤率或門數放大因子：E 括號 C 括號。

Classiq 一般允許你給出一個向量型成本函數，例如：

對於資源度量的形式化，Classiq 在實作層會將成本函數轉換為 整數線性成本（或更一般的混合整數非線性成本），這使得許多子問題可被視為：

條件是：A 乘上 x 小於等於 b，而且 x 要屬於集合 D。

其中 x

3.2 高階算子與量子算術的自動合成

許多量子演算法（如 Shor、HHL、量子金融定價）都依賴大規模的 可逆算術 (reversible arithmetic)：加法、乘法、模運算等。Classiq library 中提供了大量這類元件的高階規格，並由合成器自動產生最佳化電路。

3.2.1 可逆加法器的合成與複雜度分析

考慮最簡單的 n-bit 可逆加法：
A、d、d，下標 n，定義成：ket x tensored ket y，對應到 ket x tensored ket，x 加上 y，在模二的 n 次方之下。

在 Clifford+T 門集上，經典結果表明可以藉由 ripple-carry、carry-lookahead 或 Fourier-based 技巧合成不同複雜度的電路。

例如一個簡化的 ripple-carry 可逆加法器，其兩體閘數量與深度大致為：
G 二加上括號 Add 下標 n，等於，大 O 括號 n 括號。

下一行：D 加上括號 Add 下標 n，等於，大 O 括號 n 括號。

若進一步實現為 Clifford+T 門集，則 T 門成本大致為：
T 括號 Add 下標 n，等於 c 下標 T 乘上 n，加上一個 big O 的一。

其中 c 下標 T
 取決於基本 Toffoli 的 Clifford+T 分解（例如每個 Toffoli 需要 7 個 T 門，則 c 下標 T 大約等於 7 乘上 Toffoli 數，再除以 n。
）。

Classiq 在高階 level 允許使用者僅指定「需要 n-bit 加法」，並加上對 T-count 或 ancilla 數的約束，例如：

n = 32

b = md.qreg("b", n)

# 高階加法規格
adder_block = adder(a, b)

# 設定資源約束
md.set_constraints(
 max_qubits=100,
 optimization_metric="T_COUNT" # 或 "DEPTH", "WIDTH" 等
)

model = md.build()

在內部，這對應到選擇某一族 加法實現家族 大括號裡面是一整組的Ａ下標 i。
，每個 唸成：「黑板粗體的 A，下標 i。」
 對應一種設計（例如 ripple-carry、Fourier-based、carry-lookahead），各自有：
括號裡面依序是： 
n 下標 q 括號 A 下標 i，逗點，D 括號 A 下標 i，逗點，T 括號 A 下標 i，逗點，G 下標二 括號 A 下標 i。然後外面是一整組大括號起來。

平台則於此設計空間中選擇滿足約束且成本最小的實例。

3.3.1 一般 unitary 的分解問題

對任意 這個就是一個符號「n」。
-qubit unitary U 是二的 n 次方維度的酉群裡面的一個元素。
，已知可以用有限多個 Clifford+T gate 精確或近似地實現。理論上，任何 U
 可被分解為一系列兩體閘：
U 等於，從 k 等於一到 m 的所有 G 下標 k 相乘的乘積。 
而且每一個 G 下標 k 都屬於那個二體閘的集合 𝒢 二。

其中 唸作：「花體的 G，底下是一個二。」
 是兩體 gate 集合（例如 U3 on single qubit + CNOT）。而標準分解（如 CSD, QR-based）有：
m 等於 order 四的 n 次方。

這在實務上當然過大，因此 結構性 是關鍵：實際使用時，多數 U
 具有特殊形式（稀疏、block diagonal、tensor product 結構等）。

Classiq 的策略是：不鼓勵使用者直接給一個 二 的 n 次方 乘上 二 的 n 次方。
 矩陣，而是使用高階元件（QFT、控制旋轉、oracle 組合）描述 U
，讓合成器在這個高階結構上做最佳化。而在少數需要直接從矩陣合成時，則利用已知的結構性分解算法（如 CSD、KAK 分解對兩 qubit 的最簡化）。

以兩 qubit 的 KAK 分解為例，任何 U 屬於 S U 四。
 可分解為：
U 等於括號 k1 張量 k2 括號，乘上指數函數，裡面是 i 乘上括號， 
c1 乘上 sigma x 張量 sigma x，加上 c2 乘上 sigma y 張量 sigma y，加上 c3 乘上 sigma z 張量 sigma z，括號， 
再乘上括號 k3 張量 k4 括號。

其中 k 下標 j 是屬於 SU 二 群。
，c 一、一、c 二、c 三，都屬於實數集合。

3.3.2 QFT 的結構性合成與近似

量子傅立葉轉換 Q F T 底標 n。
 定義為：
Q F T 下標 n 作用在 ket x 上，等於，二的 n 次方開根號分之一，乘上，從 y 等於零到二的 n 次方減一的總和，裡面是，e 的二派 i x y 除以二的 n 次方次方，乘上 ket y。 
其中，x 屬於零到二的 n 次方減一這一整個集合。

標準分解為：

 對每個 qubit 這個就念作：「小寫的 j」。
 套用 Hadamard 門；

 對不同 qubit 間施加控制相位旋轉 R 下標 k
；

 最後反轉 qubit 順序。

其門數與深度滿足：
G 二，括號裡面 Q F T 下標 n，等於 big O 的 n 平方。

若允許一定誤差 唸作：「epsilon」。
，則可忽略小角度的 R 下標 k
 門，得到近似 QFT：
Q F T，下標 n，加上括號 epsilon，近似等於 Q F T，下標 n。

3.4 約束最佳化與資源權衡：形式理論與 Classiq 實作

本節討論如何在形式上描述資源 trade-off，並對應至 Classiq 的約束設定與內部求解機制（以抽象層次說明，不涉及專利實作細節）。

3.4.1 多目標最佳化與 Pareto-front

假設我們關注兩個資源：qubit 數 n 底下那個小 q。
 與電路深度 這裡就是一個大寫的英文字母 D。
。任何電路 C
 對應一個點：
r 向量，在括號裡面帶入 C，等於一個有序對，前面是 n 下標 q 的 C，後面是 D 的 C。這個有序對屬於自然數的平方，也就是自然數二維空間裡的元素。

設整個設計空間的資源像為：
黑體的 R 等於一個集合，裡面包含所有小寫粗體 r 括號 C，滿足 C 屬於黑體的 C，並且 C 滿足大寫的 Spec。

我們說 向量 r 一，下標的一，等於括號裡面 q 一、逗號、d 一。
 支配 向量 r 下標二，等於括號裡面 q 二、逗號、d 二。
（記為 向量 r 一，比向量 r 二還要小。
），若：
 小於等於 ， 小於等於 ，而且至少有一個是嚴格小於。

則不被任何其他點支配的點形成 Pareto-front：
P 等於大括號裡面所有的 r 向量，這些 r 向量屬於集合 R，並且滿足：不存在任何 r 反撇，屬於同一個集合 R，而且 r 反撇在偏序關係底下比 r 還要小。

理論上，一個「完美」的合成器應該枚舉或近似 大寫花體的 P。
，但實際問題維度很高且大寫的花體 C。
 極巨大，因此 Classiq 採用：

 使用者給定偏好（單一 optimization metric 或權重），將多目標問題轉換為標量成本；

 在內部對關鍵子模組（如加法器、乘法器）儲存多種設計點，用類似 離散 Pareto-front 的資料表來做快速選擇。

形式上可理解為：預先對重要元件 B 下標 j
 建立集合 花體的 P 底下標 j 是自然數的 k 次方集合裡面的一個子集合。
（k 種資源），在合成複雜演算法時，整體資源即為這些元件選擇的和，再加上互連開銷。最佳化問題變成一個整數規劃問題：
我要最小化，對所有 j 跟所有 ℓ 的和，x 下標 j ℓ 乘上 c 下標 j ℓ。

在條件下面：

第一個，對每一個 j，所有 ℓ 的 x 下標 j ℓ 加總等於一。

第二個，對所有 j、所有 ℓ 的 x 下標 j ℓ 乘上 r 下標 j ℓ、括號上標 m，的總和，要小於等於大寫 R 上標 m 的最大值；這個 m 可以是 qubits、depth、T-count，等等這些資源種類。

最後，x 下標 j ℓ 只能取零或一。

其中：

 x 的 j 逗點 ℓ 分量
 表示是否選擇元件 B 下標 j

 個設計點；

 r 的上標 m，底下是 j 逗號 ℓ。
 為該設計點在第 m

 R 最大，上標 m。
 為使用者設定的最大可用資源。

直覺上，研究者可以將 Classiq 視為：「我給出一個帶有參數的量子演算法模板，以及一組線性/非線性資源約束；平台回傳滿足這些約束的某個（近似）成本最小解。」這與許多經典硬體設計流程（如 HLS, High-Level Synthesis）類似，只是目標平台是量子電路與量子硬體。

3.5 Oracle 與布林函數的量子實現

許多量子演算法的核心是 Oracle：對某個布林函數 f 從零一的 n 次方，也就是所有長度為 n 的零一串，映到零一這個集合。
 建立可逆 oracle：
U f 作用在 ket x、ket y 上，等於 ket x，乘上 ket y 异或 f of x。

Classiq 提供從高階布林描述（甚至經典程式語言片段）自動合成 oracle 電路的能力。

3.5.1 布林函數的 Toffoli 網路實現

任何布林函數 這個就念成：「f」。
 可被表示為一個 CNF 或 DNF，或更高階的 BDD, AIG, ESOP 等結構。對於 N-bit 輸入：
f of x 等於，對所有 i 的 m i of x 做一次大的 XOR 直和運算。

其中 念作：「m 下標 i」。
 是單項（monomial），例如：
咪下標 i 的函數在 x 的值，等於 x 下標 j 一，乘上 x 下標 j 二，一直到乘到 x 下標 j k。

或含取反的 literal。

可逆實現 U 下標 f
 的一種標準方法是對每個項 念作：「m 下標 i」。
 合成一個多控 NOT 門（generalized Toffoli）：

念作：

「 下標 作用在 ket 再乘上 ket ，等於 ket 乘上 ket 括號裡面是 XOR 括號 。」

若有 L
 個 monomial，則：
U 下標 f 等於，從 i 等於一到 L 的乘積，裡面每一項是 U 下標 m 下標 i。

然而多控 NOT 的實現成本與輸入數目 k
 成線性或對數成長（取決於是否有 ancilla）。例如，無 ancilla 的 Barenco construction 對一個 k
-控 NOT 的 CNOT 數量約為 大 O 括號 k 的平方 括號。
，而若允許 k 減掉 2
 個 ancilla，則可做到 O 括號 k 括號。
。

Classiq 在面對布林規格時：

 首先選擇內部表示形式（例如 BDD/AIG/ESOP）；

 依據資源約束決定是否大量使用 ancilla；

 最終合成一個 Toffoli/CNOT 網路，再映射到 Clifford+T。

整體資源估計（簡化版）可表示為：
第一行念作：

「G 二，小括號 U f，小於等於，從 i 等於一到 L 的總和，c 二，小括號 k i。」

第二行念作：

「T，小括號 U f，小於等於，從 i 等於一到 L 的總和，c 下標 T，小括號 k i。」

其中 k 下標 i
 為每個 monomial 的控制變數數目，念作：

「c 二 括號點，逗號，c 大寫 T 括號點。」
 受選擇的多控 NOT 實現策略影響。

3.6 Classiq 中的控制流、參數化與可重複使用模組

Classiq 不只是一個「一次性」合成器，而是支援 模組化 (modularity) 與 參數化 (parametrization)，並在此結構上進行全域最佳化。這一點對於大規模量子演算法設計尤其重要。

3.6.1 量子子程式與 call-graph 的最佳化

考慮一個演算法由多個子程式組成：
A 等於第一個子程序，上一個小括號 t 一，下標是一，然後跟第二個子程序，上一個小括號 t 二，下標是二，這樣一路用函數複合一路串下去，到第 k 個子程序，上一個小括號 t k，下標是 k。

其中 唸作：「第 j 個子常式，上標括號 t 下標 j。」
 代表子程序第 t 下標 j
 次呼叫。有時，最佳化的關鍵不在單一子程式，而是如何在多次呼叫間重用 ancilla、重新安排調度等。

若將每個子程式粗略規約為一個資源向量 向量 r 下標 j，等於括號裡面： 
n 下標 q 上標 j，逗號，D 上標 j，逗號，T 上標 j，逗號，然後點點點。
，則整體資源不是簡單的和，而取決於：

 是否允許子程式平行執行（qubit 不重疊）；

 是否可在不同呼叫間釋放並重用 ancilla；

 是否存在跨子程式的電路等價變換（如合併連續的單 qubit 旋轉）。

這可以形式化為一個 排程與佈局問題：
給定：一組子程式 ，還有各自的 qubit 使用模式。

求：一個 qubit–time 的佈局，讓最大的時間軸長度，也就是電路的深度，或者 qubit 的高度，被最小化。

這與經典的 resource-constrained scheduling 和 register allocation 類似。Classiq 會在 call-graph 層級做這類最佳化，使得模組化開發不犧牲全域資源效率。

3.6.2 參數化電路與符號運算

對於變分量子演算法（VQE, QAOA 等），Classiq 支援符號參數（symbolic parameters），並在合成時保留這些參數，以便後續與經典 optimizer 一起使用。

考慮一個參數化單 qubit 門：
R 下標 z 括號 theta，等於 exp 括號負的 i 乘上 theta 乘上 Z 除以二，關括號，等於一個二乘二的矩陣，左上角是 e 的負 i theta 除以二 次方，右上角是零，左下角是零，右下角是 e 的正 i theta 除以二 次方。

在 Classiq 模型中，希塔
 可是一個符號變數，稍後在執行時才由經典程序提供具體數值。對於整個電路 C 括號 theta 向量
，我們可視其對應的 unitary 為：
U 括號 θ 向量，等於 對所有 k 的 G 下標 k 括號 θ 下標 σ 括號 k 的連乘積。

其中 西塔，下標 sigma 括號 k。
 表示第 k
 個 gate 的參數來源。

在 VQE 中，我們通常最小化期望值：
E 括號 theta 向量，等於 bra 零，接著是 U 括號 theta 向量 的 dagger，乘上哈密頓算符 H，再乘上 U 括號 theta 向量，最後作用在 ket 零。

Classiq 允許我們只定義 H
 與 U，小 theta 的向量。
 的結構，再透過平臺與外部優化器（如 SciPy, PyTorch, JAX）整合。內部來說，這要求合成時維持 gate 參數的抽象，而非將它們「編譯到常數」。

在 DSL 層次會類似：

from classiq import ModelDesigner, Parameter
from classiq.builtin_functions import ry_rotation_layer

md = ModelDesigner()
n = 8

layer = ry_rotation_layer(x, theta)

# 其他 block，如 entangling layer 等
# ...

model = md.build()

對研究者而言，這意味著可以在高階層次設計「符號電路族」，並利用 Classiq 為該電路族合成在給定拓撲與資源約束下的高效實現。

3.7.1 量子硬體拓撲與 SWAP 網路

設硬體有 這個念作：「大寫的英文字母 N。」
 個實體 qubit，其耦合圖為：
G 等於括號 V 逗點 E 括號，然後豎線 V 豎線等於 N。

其中每個頂點 v 屬於 V。
 對應一個 qubit，每條邊 括號 u 逗號 v 括號，屬於大寫的 E。
 表示可直接實作兩體閘（如 CNOT）。

合成得到的邏輯電路 C
 通常假設所有 qubit fully connected。為了在拓撲 G
 上執行，需引入 SWAP 門將要互動的邏輯 qubit 移動到相鄰物理 qubit。這對應於一個 routing problem：

 給定一系列兩體 gate CNOT，括號裡面 qi 逗號 qj。
 的序列；

 給定 qubit 的初始映射 pi 零，冒號，從 logical 映到 V。
；

 透過插入 SWAP 門產生新的電路 C 撇。
，使得每個兩體 gate 在硬體上可實作。

形式上，這可以表述為尋找一條最短路徑：
最小化，電路 C 拿來做完 SWAP 的次數，條件是：電路 C 拿來做完以後得到的 C 撇，跟原本的 C 在邏輯層上是等價的。

或更進一步最小化延遲（深度）而非僅是 SWAP 數量。

這是一個 NP-hard 問題（與圖上的嵌入與 VLSI routing 有關）。Classiq 在高階層即可納入拓撲資訊，例如（虛擬語法）：

from classiq import ModelDesigner, HardwareTopology

md = ModelDesigner()

# 設定硬體拓撲 (如 'line', 'grid', 'heavy_hex', 或自訂圖)
topology = HardwareTopology.from_ibmq_device("ibm_hanoi")

md.set_topology(topology)

# ... 定義高階模型 ...

model = md.build()

這樣合成器在設計高階運算子時就已知道拓撲限制，可以提前：

 選擇更適合拓撲的電路實現（如線性鏈上偏向 nearest-neighbor-friendly 的 QFT）；

 在大型子電路內部安插可 reuse 的 SWAP pattern；

 同時考量路由成本與本身 gate 成本，進行整體最佳化。

3.7.2 圖論觀點：電路映射為圖嵌入

形式上，可以將邏輯電路的兩體交互關係抽象成一個「邏輯互動圖」：
H 等於括號 Q 逗號 E 下標 H 括號。

 整體 cost，如 總和取遍所有在圖 裡面的邊 ，每一項是，圖 裡面 phi 作用在 跟 phi 作用在 這兩點之間的距離。

這類問題與 graph embedding、minimum bandwidth、quadratic assignment problem (QAP) 密切相關。Classiq 在實作中不會嘗試求全域最優，而是基於啟發式與局部重排演算法，結合高階模組化與排程資訊，得到實務上良好的映射。
