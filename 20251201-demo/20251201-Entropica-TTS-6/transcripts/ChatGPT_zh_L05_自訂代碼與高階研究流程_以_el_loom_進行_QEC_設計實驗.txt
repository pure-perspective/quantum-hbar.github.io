1. 量子糾錯研究流程與 el-loom 的角色

1.1 典型 QEC 研究問題

博士階段與進階研究者在 QEC 領域常見的研究問題包括：

 為特定硬體限制（耦合圖、退相干機制、量測頻率）設計新的穩定子碼。

 針對已知碼（如 surface code, color code）在非對稱噪聲或具體硬體噪聲下重新評估閾值。

 研究新型解碼器（neural decoder, tensor-network decoder, belief propagation, etc.）的效能。

 設計自訂的量測排程、閘排程（schedule），分析捨入誤差與時間相關噪聲的影響。

 比較不同碼族（code families）在漸近尺度（asymptotic scaling）上的邏輯錯誤率表現。

這些問題的共同需求是：能快速、系統性地把「抽象的碼結構＋噪聲模型」轉成「可重現的數值實驗」。el-loom 正是為此設計的一套 Python 工具，重點在於：

 對穩定子碼與量測主體（measurement circuits）的統一抽象。

 與 stim 等高效模擬器整合，進行大規模蒙地卡羅模擬。

 支援多種解碼器與輸出格式，便於後續資料分析。

2.3 在 el-loom 建立自訂碼的核心概念

在 el-loom 中，核心抽象並非只是一個靜態的 H 下標 S。
，而是：

 幾何／拓樸資料： qubit 位置、鄰接關係、層級結構（如 lattice, tiling）。

 穩定子、邏輯算符的 Pauli 結構： 可視為 algebraic layer。

 測量電路與 schedule： 如何在時間上實現這些穩定子的量測。

具體到 Python，典型流程（以 pseudo-code 表示）如下：

from loom import codes, circuits, layouts

# 1. 定義 qubit layout (可 1D, 2D, graph-based)
layout = layouts.CustomLayout(qubits=range(n), connectivity=edges)

# 2. 定義 stabilizer 與 logical Pauli
stabilizers = [
 "X0 X1 X3 X4", # textual Pauli representation
 "Z1 Z2 Z4 Z5",
 # ...
]
logical_x = ["X0 X2 X4", ...]
logical_z = ["Z1 Z3 Z5", ...]

code = codes.StabilizerCode(
 n_qubits=n,
 stabilizers=stabilizers,
 logical_x=logical_x,
 logical_z=logical_z,
 layout=layout,
)

# 3. 從 code 構造 syndrome measurement circuit
meas_circuit = circuits.SyndromeMeasurementCircuit.from_code(code)

實際 API 名稱請以官方文件為準，上述示例只展示「抽象層級」。核心思想是：

 你應該把自訂碼的數學規格（穩定子、邏輯算符）明確寫入。

 幾何（layout）是為了實現局域性約束與 schedule 建構。

 電路（circuit）是為了後續噪聲插入與模擬。

4. 噪聲模型與時間結構的嚴謹建模

4.1 噪聲通道的抽象與 local noise 假設

在 QEC 理論分析中，我們通常假設 局域獨立噪聲（local stochastic noise）。在一個單步（time slice）內，每一個受控物理操作（閘、量測、idle）都可能伴隨獨立噪聲通道：
E 作用在 rho 上，等於一減掉 p 乘上 rho，加上對 i 求和，p 下標 i 乘上 E 下標 i，rho，再乘上 E 下標 i 的 dagger。

常見簡化為：

 單比特 depolarizing：
 D 下標 p 作用在 rho，等於一減掉 p，乘上 rho，加上 p 除以三，乘上括號裡面： 
X 乘上 rho 再乘上 X，加上 Y 乘上 rho 再乘上 Y，加上 Z 乘上 rho 再乘上 Z。

 二比特 depolarizing：
 大 D 上標括號二，下標 p，作用在 rho，等於括號一減 p 括號乘上 rho，加上 p 除以十五，乘上對所有屬於大 P 二、但不要 II 的那些 P 做總和，裡面的項是 P 乘上 rho 再乘上 P dagger。

 非對稱噪聲（p 下標 X 不等於 p 下標 Z。
）：
 E 作用在 rho 上，等於一減掉 p 下標 X 再減掉 p 下標 Z，乘上 rho，加上 p 下標 X 乘上 X、rho、X，再加上 p 下標 Z 乘上 Z、rho、Z。

在更實際的硬體場合，也會考慮 amplitude damping、dephasing、crosstalk 等非 Pauli 噪聲，但在 Pauli twirling approximation 下，常用 Pauli channel 近似，便於與 Stim 這類 Pauli 模擬器接軌。

4.2 在 el-loom 中指定噪聲模型

el-loom 通常透過一個「噪聲規則集」來描述：

 對應到哪種 gate / measurement / idle。

 概率參數（單一標量 這個就是一個小寫的英文字母 **p**。
 或多參數 左括號， 下標 、逗號、 下標 、逗號、一直到點點點，右括號。
）。

 是否 time-correlated（跨周期關聯）。

概念性範例：

from loom import noise

noise_model = noise.NoiseModel()

# 單比特 gate depolarizing
noise_model.add_gate_noise(
 gate_type="H",
 noise="depolarizing",
 p=1e-3,
)

# CNOT 的二比特 depolarizing
noise_model.add_gate_noise(
 gate_type="CNOT",
 noise="two_qubit_depolarizing",
 p=2e-3,
)

# 量測錯誤
noise_model.add_measurement_noise(
 basis="Z",
 p_meas=5e-3,
)

對應到理論分析，我們希望保證 model 中的 noise channel 大寫花體的 E，底下標註 hardware。
 與理論假設 大寫花體的 E，下標寫 theory。
 在 diamond norm 上接近：
鑽石範數下，硬體實際的超算符減掉理論上的超算符，遠小於一。

或至少在實驗設計中清楚說明採用之近似（如 Pauli twirling）。

4.3 時間結構與循環（cycles）

QEC 通常以 循環（cycle） 為單位：每個 cycle 執行一次完整的 syndrome measurement 序列。從邏輯態 rho 下標 L
 開始，經過 這個就是一個大寫的英文字母 **T**。
 個 cycle 後：
rho 下標 L 的括號 T，等於「R 接著 M 接著 N」這個組合算符的 T 次方，作用在 rho 下標 L 上。

其中：

 大寫花體的 N。
：實際噪聲通道（包含 gate noise, idle noise）。

 這個就是花體的大寫英文字母 M。
： syndrome measurement 與 classical post-processing（decoder input）。

 大寫的花體 R。
： decoder 產生的恢復算符。

在 el-loom 的設計裡，會以「repeated circuit」或「cycle template」方式實作：

from loom import circuits

cycle_circuit = circuits.SyndromeMeasurementCircuit.from_code(code)

# 疊加噪聲
noisy_cycle = cycle_circuit.with_noise(noise_model)

# 重複 T 次
T = 100
full_circuit = noisy_cycle.repeat(T)

此種 time-structured circuit 再交給 Stim 等底層模擬器，即可獲得對應長時間演化下的邏輯錯誤統計。

5. 測量電路設計與錯誤傳播分析

5.1 CNOT-based syndrome extraction

對於一個穩定子 S 等於，從 j 等於 1 到 n，所有 P 下標 j 的張量積。
（其中 P 下標 j 屬於大括號裡面的 I、X、Y、Z。

 引入一個 ancilla qubit a

 對每個物理 qubit 就念成：「小寫的 j」。

 最後量測 ancilla 在 Z

大寫的 M 下標 S，等於，對 s 等於正一和負一做總和，把 s 乘上大寫的 Π 下標 s。

5.2 在 el-loom 中自訂測量 schedule

el-loom 提供兩種典型策略：

 自動生成 schedule： 根據穩定子的 support 與 layout，嘗試產生無衝突、深度盡量小的電路。

 手動指定 schedule： 研究者自行定義多輪 CNOT 與 ancilla 使用策略，精細控制錯誤傳播結構。

一個手動指定的示意：

from loom import circuits

builder = circuits.CircuitBuilder(code)

# 為某個 Z-type stabilizer S_1 設計量測電路
anc = builder.new_ancilla(init="0")

# round 1: CNOTs on disjoint pairs
builder.cnot(control=0, target=anc) # Z on data 0
builder.cnot(control=3, target=anc) # Z on data 3

# round 2: next layer
builder.cnot(control=1, target=anc)
builder.cnot(control=4, target=anc)

# measure ancilla in Z
builder.measure(anc, basis="Z")

syndrome_circuit = builder.to_circuit()

利用這種 builder 介面，可以針對：

 避免多個 ancilla 同時接觸相鄰 qubit（降低 correlated error）。

 優化 circuit depth（考量 T1/T2 decoherence）。

 插入 idle gate 噪聲模型。

並可將這個「局部 stabilizer 量測電路」複製到所有 face/star，組成一個完整 cycle。

7. 閾值與縮放律分析：多碼距實驗設計

7.1 閾值的嚴謹定義與 scaling ansatz

一個 QEC code family 大括號，裡面放一個帶底線 d 的粗體大寫 C。
（如距離 d 等於 3、5、7，一直這樣下去。
 之 surface code）在某種噪聲模型下有閾值 p，下標 t h。
，若存在 p 的下標 t h，大於零。
 使得：
對所有小於臨界機率的 p，當 d 趨近無限大時，p 下標 L 括號 p 逗點 d 會趨近於零。

另一方面，若 p 大於臨界機率 p 下標 t h。
，則 當維度 d 趨近無窮大的時候， 
p 下標 L 括號裡面是 p 跟 d，的 lim inf 大於零。
。

在數值實驗中，常假設近閾值區域遵守 scaling ansatz：
p 下標 L，括號裡面帶變數 p 跟 d，大約等於一個函數 f，裡面的自變數是括號 p 減掉 p 下標 t h，也就是臨界的那個 p，整個再乘上 d 的一除以 ν 次方。

其中 唸作：「紐」。
 為相關長度臨界指數，這個就是「f」。
 為某 universal scaling function。對 fixed 這個就是一個小寫的英文字母 d。
 掃描 這個就是一個小寫的英文字母 **p**。
，再對不同 這個就是一個小寫的英文字母 d。
 作 collapse 分析，可同時估計 p，下標 t h。
 與 唸作：「紐」。
。

 "distance": d,
 "p_phys": p,

8. 自訂碼設計實驗：從幾何到代碼優化

8.1 問題設定：為非對稱噪聲設計最佳碼

考慮一個具體研究問題：

給定一個硬體噪聲模型，其 Z
-錯誤遠多於 X
-錯誤（如 dephasing-dominated noise），希望設計一個在固定 qubit 數下最小化長時間邏輯錯誤率的穩定子碼。

數學上，我們可以將噪聲通道 parameterize 成：
E 作用在 rho 上，等於，括號一減掉 p 下標 Z 再減掉 p 下標 X，乘上 rho，加上 p 下標 X 乘上 X、rho、X，再加上 p 下標 Z 乘上 Z、rho、Z。

並假設 p 下標 Z 遠大於 p 下標 X。
。對一個代碼 這個唸作「花體的大寫 C」。
，可定義「X-type distance」與「Z-type distance」：

 d 下標 X
：造成 上橫線的 X。
 邏輯錯誤的最小 Z-type 錯誤 weight。

 念作： 
「d 下標 Z」。
：造成 Z 上面加一槓。
 邏輯錯誤的最小 X-type 錯誤 weight。

在 p 下標 Z 遠大於 p 下標 X。
 下，我們希望 d 下標 X 遠大於 d 下標 Z。
，即對 dominating noise 方向拉高距離。

8.2 幾何設計空間與搜尋策略

在 el-loom 中，可以設計一個 parametric code family：

 幾何參數：如長寬比 L 下標 x 乘上 L 下標 y
 的 rectangular surface code。

 邊界型態：smooth/rough 邊界組合。

 穩定子選擇：是否引入變形 plaquette/star。

例如 rectangular surface code 中：
d 下標 X 等於 L 下標 x，逗號，d 下標 Z 等於 L 下標 y。

（視具體邊界選擇而定），則在 p 下標 Z 遠大於 p 下標 X。

 以優化。

# 然後進行迴圈模擬，將結果寫入 data/raw/

此種方式有利於：

 分享實驗設定：只需分享 config + commit hash。

 在 cluster 上 parameter sweep：以 config 為單位派發 job。

 日後對同一實驗在不同硬體／el-loom 版本上重跑。

11. 小結與延伸方向

本課程從穩定子碼的嚴謹數學定義出發，說明如何將其映射到 el-loom 的資料結構與模擬流程，並展示高階研究者在「自訂代碼與設計實驗」時可採用的完整 pipeline：

 設計或選擇一個 code family，建立其穩定子與邏輯算符表示。

 在 el-loom 中定義 code + layout，生成或自訂測量電路與 schedule。

 建模噪聲通道（包含非對稱、時間結構、硬體特有效應）。

 選擇與實作解碼器，使用蒙地卡羅模擬估計邏輯錯誤率。

 設計多碼距、多參數掃描實驗，進行閾值與 scaling 分析。

 利用 parametric search 探索最佳代碼幾何或結構（如非對稱碼）。

 將 syndrome/data 匯出，連接外部 ML 或 tensor-network 解碼器。

 透過 config 驅動與良好專案結構，確保實驗的可重現性。

下一步你可以嘗試：

 實作一個小型但 novel 的自訂碼（例如帶 dislocation 的 surface code），在 el-loom 中完整建立並比較其性能。

 針對具體硬體參數（實驗室提供的 T1/T2, gate fidelity, readout error）建立 realistic noise model，重新評估某碼族的實用閾值。

 將 el-loom 產生的 syndrome history 匯出，訓練一個 neural decoder，與傳統 MWPM 作系統性比較。

隨著 el-loom 與周邊工具的演進，這套工作流程可以輕易擴展至 concatenated codes、LDPC codes、subsystem codes 等更複雜的架構，在理論與實務之間搭建更順暢的橋梁。
